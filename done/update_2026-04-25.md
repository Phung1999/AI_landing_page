## 1. Tính năng Clone Landing Page (MỚI)

### Mô tả
- Thêm chức năng copy landing page từ URL thực
- Parse đầy đủ: ảnh, cấu trúc, font, màu sắc
- Dùng Playwright để render JS và lấy nội dung chính xác
- Hiển thị progress bar khi đang clone

### Backend Files mới

| File | Mô tả |
|------|-------|
| `backend/app/services/clone_service.py` | Clone service với Playwright |
| `backend/app/routes/clone.py` | Clone API endpoints |
| `backend/app/models/__init__.py` | Project SQLAlchemy model |

### Backend Dependencies mới
```
playwright==1.58.0
```

### API Endpoints mới

| Method | Endpoint | Description |
|--------|---------|------------|
| POST | /api/clone | Crawl URL → trả về sections |
| POST | /api/projects | Lưu project vào DB |
| GET | /api/projects | List tất cả projects |
| GET | /api/projects/{id} | Get chi tiết project |
| DELETE | /api/projects/{id} | Xóa project |

### Frontend Files đã sửa

| File | Thay đổi |
|------|---------|
| `frontend/src/App.tsx` | Thêm UI copy URL, progress bar, Gallery component |

### Frontend Files mới

| File | Mô tả |
|------|-------|
| `frontend/src/components/sections/Gallery.tsx` | Gallery section component |

### Database

- SQLite: `backend/projects.db`
- Table: `projects`
- Columns: id, name, url, landing_type, sections (JSON), theme (JSON), created_at, updated_at
