# AI Landing Page Generator

Công cụ tự động tạo Landing Page chuyển đổi cao từ mô tả văn bản bằng AI.

## 🚀 Khởi động nhanh

Để chạy cả Backend và Frontend, chỉ cần chạy file:
```bash
run.bat
```

## 🛠 Tech Stack

- **Frontend:** React 18, Vite, Tailwind CSS v4, Zustand, shadcn/ui.
- **Backend:** FastAPI (Python), OpenAI GPT-4o, SQLite.

## 🌟 Tính năng chính

1. **AI Generation:** Nhập mô tả, AI sẽ tự động sinh các section phù hợp.
2. **Template Gallery:** Chọn từ các mẫu có sẵn (Course, SaaS, Product).
3. **Inline Editing:** Nhấp và sửa văn bản trực tiếp trên bản xem trước.
4. **Theme Customizer:** Thay đổi màu sắc và font chữ linh hoạt.
5. **AI Refinement:** Yêu cầu AI chỉnh sửa giao diện bằng văn bản.
6. **Export HTML:** Xuất mã nguồn HTML/CSS hoàn chỉnh để sử dụng ngay.

## 📁 Cấu trúc thư mục

- `frontend/`: Mã nguồn giao diện (React).
- `backend/`: Mã nguồn API (FastAPI).
- `done/`: Tài liệu kế hoạch và tiến độ dự án.
